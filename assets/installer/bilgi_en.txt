Revora — PDF Editor
===================

Revora lets you edit the text in PDFs with the original font, size and colors;
manage table lines with the mouse; and do markup, page, watermark and form tasks
in one program.

Installation options
--------------------
• Installing only for yourself does not require administrator rights.
• The "Open with Revora" option on the right-click menu of PDF files is optional;
  it does not change your default PDF program.
• The program language can be changed later in Settings > Language.
